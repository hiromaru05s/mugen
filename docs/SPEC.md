# 夢幻の森 — 技術仕様 v0.2

## 0. ネットコード(全設計の背骨)
サーバー権威+スナップショット補間。ロールバック不使用。

- クライアント: 入力送信(移動ベクトル+スキル発動)。自機のみ予測移動
- サーバー: **20Hz固定tick**で全シミュレーション(唯一の真実)
- クライアント: 受信スナップショットを100〜150ms遅延で補間描画

### ネットコード制約 → ゲーム仕様への変換(必ず守る)
| 制約 | 仕様 |
|---|---|
| 実効遅延150〜250ms許容 | TTK 4〜8秒。ワンパン即死なし |
| フレーム精度判定なし | 全スキルは予兆(テレグラフ)方式。発動0.3〜0.8秒前に範囲表示 |
| 回避はサーバー判定 | 反射でなく「予兆を見た位置取り」で避けるゲームにする |
| 弾も補間対象 | 弾速300〜600px/s。誘導弱め。遠距離職の強さは射線・地形選定に置く |

## 1. 技術スタック
- クライアント: **Phaser + TypeScript**(タイルマップ・アニメ・入力を内蔵)
- サーバー: **Colyseus (Node/TS)** — 1試合=1ルーム。スキーマ差分同期・マッチメイキング内蔵
- 永続層: **Supabase**(アカウント・RP・戦績。試合終了時にゲームサーバーが書込)
- 配信: クライアントは静的配信(GitHub Pages / itch.io)。ゲームサーバーのみ常駐が必要

## 2. ワールド
- 32pxタイル、約400×400タイルの同心円バンド構造:
  - バンド0(外周): スポーン圏・弱モブ・基礎素材
  - バンド1: 浅層 — 宝箱・NPCクエスト・商人
  - バンド2: 深層 — 強モブ・ギミック・高級宝箱
  - コア: ドラゴンの巣(開始時封印 → 10分で開放)
- 生成: **手作りチャンク(20×20タイル)のプロシージャル配置**(Enter the Gungeon方式)
- 収束圧: 縮小リングではなく**「外周から森が枯れる」** — 枯死域は視界悪化+継続DoT+モブ凶暴化
- 視界: サーバー側計算、見えない敵の座標は送信しない(interest management 兼 ウォールハック対策)

### 2.5 視界ルール v0.2(プロトタイプ検証済み — 本実装はこの仕様に従う)
| 要素 | ルール |
|---|---|
| 視界半径 | 750px。**枯死域内の観測者は350px**(枯死圧=視界悪化) |
| 茂み(エリア型隠蔽) | 中のユニットは敵チームから不可視。敵が同じ茂み(+周縁24px)に入ると見える。シアンの実を目印にする |
| 木(射線遮蔽) | 木の円が観測者-対象の線分を遮ると不可視。チームの誰か1人でもクリアな射線+視界半径内なら可視(視界はチーム共有) |
| 露見(reveal) | 攻撃で1.4s / 被弾で0.8s、距離・遮蔽を無視して可視化。狙撃・ブッシュ内攻撃の代償 |
| 当たり判定 | 視界と**独立**。茂みへのブラインド攻撃は当たる(炙り出しが成立する) |
| 隠密(盗賊) | 視界ルールの上位。描画・索敵・被弾対象からも除外(現仕様) |
| 適用範囲 | 描画・ミニマップ・AI索敵・モブ索敵すべて同一ルール |

### 2.6 操作(プロトタイプ検証済み)
- 2モード選択制。**キーボード**(デフォルト): 矢印移動 / Q攻撃=視界内の敵へ自動照準(射程+130pxのマグネット、いなければ向いている方向) / W・Eスキル / Rポーション。**マウス**: WASD+マウス照準
- ブリンク等の退避スキルは自動照準の対象外(向いている方向へ) — 敵に吸われて事故るため

## 3. サーバーシミュレーション
- tick 20Hz(50ms)。当たり判定は円+AABBのみ(物理エンジン不使用)
- 空間ハッシュ(64pxグリッド)で近傍クエリ
- モブAI: 4状態FSM(徘徊→索敵→交戦→リーシュ帰還)
- ドラゴン: フェーズ制スクリプトボス(HP75/50/25%で行動テーブル切替、予兆AoE、部位=子エンティティ。
  盗賊のギミック解除で部位露出)
- 貢献: ドラゴン与ダメをチームIDで積算 → RP=チーム与ダメ割合。
  **戦闘中はHUDにチーム別貢献%をライブ表示**(横取り無意味・共闘動機の可視化。プロトタイプ検証済み)
- バランス基準値(プロトタイプ実測): ドラゴンHPは「AIのみ4チームで討伐率5割前後」に合わせる
  (3職編成なら6000、僧侶入り5職編成なら5500相当)
- 帯域: スキーマ差分+視界フィルタで数KB/s/クライアント

## 4. スキルシステム(データ駆動)
スキル=JSON定義。実行プリミティブは以下の約10個のみコード実装:
`projectile / aoe / dash / teleport / summon / modifyStat / zone / channel / damage / status`

```jsonc
{ "id": "fireball", "castTime": 0.4, "cooldown": 6, "cost": 20,
  "telegraph": { "shape": "circle", "r": 80, "delay": 0.5 },
  "effects": [{ "type": "projectile", "speed": 450, "onHit": [
    { "type": "damage", "base": 120, "scale": "INT" },
    { "type": "status", "id": "burn", "dur": 3 }]}] }
```
- トリック魔法 = teleport + zone(スロー) + summon(壁)
- 盗賊の罠 = summon(不可視エンティティ)+検知半径判定

### 4.5 スキルセット v0.2(プロトタイプ実装済み — 全職4スキル+マナ)
マナ: 全職100、回復6/s。スキルはコスト不足で発動不可。

| 職 | s1 | s2 | s3 | s4 |
|---|---|---|---|---|
| 近接 | 突進(15) | 咆哮=攻バフ(20) | 盾打=スタン1.2s(20) | 大斬撃=広角2倍(30) |
| 魔法 | ブリンク(20) | 減速域(25) | 魔氷壁=射線+移動+弾遮断4.5s(30) | 爆裂=予兆0.6s AoE90(35) |
| 盗賊 | 罠(20) | 隠密(25) | 検知=450px強制露見3s(20) | 毒刃=3撃に毒DoT(15) |
| 僧侶 | 祝福=範囲回復90(25) | 聖域=持続回復(30) | 聖障壁=被ダメ-40% 4s(30) | 天光=単体+180(25) |
| 遠距離 | 狙撃=2.2倍+自己露見(25) | 跳躍=後方離脱(15) | マーク=12s露見+被ダメ+15%(15) | 煙幕=足元に隠蔽ゾーン5s(25) |

視界システムとの絡み: 魔氷壁は木と同じ射線遮蔽 / 煙幕は移動式ブッシュ / 検知・マークは露見の攻め筋。
状態異常: スタン(移動・攻撃・スキル不可) / シールド(被ダメ×0.6) / 毒(9/s DoT・キル帰属あり) / マーク(被ダメ×1.15+可視)。
操作: KB=W/E/R/Tスキル+Sポーション / マウス=1〜4スキル+5ポーション。
- ギミック解除ミニゲーム: クライアント実行、サーバーはシード配布+結果検証(所要時間下限チェック)
- プロトタイプ実装(v0.2): 封印装置3基(深層)。QTE=振り子ニードルを金ゾーンで3回停止(移動で中断)。
  盗賊は成功域約2倍(0.24 vs 0.11)、失敗は30ダメ+露見1.4s。AI盗賊は5秒チャネルで解除。
  報酬=チームの対竜与ダメ**+12%(累積)**+チームに120G/30xp — 「装置を回る=戦線離脱」のトレードオフを作る

## 5. 試合構造(仮数値)
- 10チーム×3人=30人 / 1試合15〜20分
- 0-3分 スポーン圏成長 → 3-10分 中層 → 10分 コア開放 → ドラゴン戦+漁夫+枯死圧 → 討伐or全滅
- 成長: Lv1-10+装備3枠+ビルド分岐2回。**試合内完結・持ち越しなし**(恒久成長はRP/コスメ側)
- ソロキュー: マッチメイクで常に3人PTに編成
