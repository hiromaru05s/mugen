# 夢幻の森 (Mugen no Mori)

2Dトップダウン PvPvE バトルロワイヤル。10チーム×3人=30人が「無限の森」を深部へ進み、
最奥のドラゴン討伐を競う。ランクポイントは**チーム単位の与ダメ割合**で配分。

## Codexへ: このリポジトリの読み方
1. `docs/SPEC.md` — 技術仕様の全体(ネットコード・ワールド・スキルシステム・マイルストーン)。実装はこれに従う
2. `docs/ART_PIPELINE.md` — アート規格(サイズ・スプライトシート・命名・取り込み)。**画像生成の前に必読**

## 設計思想(変更時はここに立ち返る)
- **身内3人で成立する**ことが最優先(ソロキューも常にトリオ編成)
- インタラクションはメカニクスに形式化する(ボイスチャット前提の面白さを作らない)
- 実力は勝敗に効いてよい。ただし**実力の帰属は個人に張り付けない**
  (RP・与ダメはチーム単位で計上。役割別の個人統計は本人のみ閲覧)
- 役割は気質で自己選択。強制しない。型破りビルドの余地を残す
- 盗賊はハイリスク・ハイキャリーの尖りを意図的に維持する

## 職業(5職)
近接(剣盾/両手剣/両手盾) / 魔法(攻撃・支援・回復・トリック=時空間) /
僧侶(超回復支援特化) / 遠距離(遠距離暗殺者) / 盗賊(罠・ギミック解除・ゴールドボーナス)

## MVPスコープ

アート優先度も同順(ART_PROMPTS.md の優先度列を参照)。
