# M0 — Colyseus+Phaser 疎通 (SPEC §6)

サーバー権威(20Hz)の最小スライス: 移動同期 / **サーバー側視界フィルタ(見えない敵は座標を送らない)** /
狼モブ1種FSM / 近接の殴り合い / 6人(3v3)・死亡3秒リスポーン。

## 動かし方(要 Node 18+)
```bash
cd m0/server
npm install        # 初回のみ(package.json同梱)
node index.js      # ws://localhost:2567 で待受
```
クライアントは `m0/client/index.html` をブラウザで開くだけ(Phaser/colyseus.jsはCDN)。
タブを複数開けば複数人。別マシンから繋ぐ場合はURL末尾に `#ws://<ホスト>:2567`。

## 実装の対応関係
| SPEC | 実装 |
|---|---|
| §0 20Hz固定tick | `setSimulationInterval(50ms)`。クライアントは描画と入力送信のみ |
| §0 100-150ms補間 | クライアントで最新snap−100msを2点線形補間 |
| §2 視界サーバー計算 | `seenBy()`(プロトタイプ§2.5と同一数式: 750px/茂み/木LoS/露見1.4s・0.8s)。チーム別スナップショットから不可視敵を除外 |
| §3 モブFSM | idle→chase(視界準拠の索敵)→予兆攻撃→leash |
| 入力の権威 | クライアントは方向・攻撃・照準角のみ送信。座標/HPは受理しない |

## M0で意図的にやっていないこと(M1以降)
- スキーマ差分同期(今は毎tickチーム別JSONスナップショット — 6人なら帯域十分。M1で@colyseus/schema+@filterへ)
- 自機の予測移動(現状は素の補間なので自機操作に~150msの遅延感がある — M1でclient-side prediction)
- スキル/成長/ドラゴン/枯死圧(プロトタイプのロジックを§4スキルプリミティブとして移植)

## 検証済み(コンテナ内統合テスト)
2クライアント接続 → 相互可視 / 片方が茂みに入ると相手のスナップショットから消える /
攻撃で露見して再出現 / 殴ればHPが減る / モブが追跡してくる — をnodeクライアントで自動確認済み。
