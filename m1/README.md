# M1 — スキルプリミティブ + 5職×4スキル (SPEC §4/§6)

M0(サーバー権威・視界フィルタ・モブ・殴り合い)の上に:
**データ駆動スキルシステム / マナ / 状態異常 / 自機の予測移動** を実装した垂直スライス。

## 動かし方(要 Node 18+)
```bash
cd m1/server
npm install
node index.js      # ws://localhost:2568 (M0と併走可)
```
`m1/client/index.html` をブラウザで開く → 職選択 → 複数タブで対戦。
操作: WASD/矢印移動・クリックorSpace攻撃・スキル=1〜4(またはE/R/T、矢印移動派はWも)・照準=マウス。

## スキルシステム(SPEC §4準拠)
スキル=**JSON定義**(`SKILLS`)、コードは実行プリミティブのみ:
`dash / teleport / projectile / meleeArc / zone(slow・heal・smoke・nuke) /
summonWall / summonTrap / stealth / revealEnemies / markTarget / modifyStat(buff・shield) /
healAllies / healLowest / venom`

5職×4スキル(プロトタイプと同一のセット・数値)を全てこのプリミティブの組合せで定義。
新スキルの追加=JSON1行。SPECの「スキル=データ、プリミティブ=コード」の形が実証済み。

## M0からの技術追加
| 項目 | 実装 |
|---|---|
| マナ | 100上限・回復6/s・コスト不足で発動不可(サーバー判定) |
| 状態異常 | スタン(入力無効)・シールド(×0.6)・毒(9/s、キル帰属)・マーク(×1.15+強制可視) |
| 壁 | サモン後は木と同格: 射線遮蔽+移動衝突+弾ブロック |
| 煙幕 | ゾーンだが視界的には移動式ブッシュ(同じcover判定) |
| 隠密 | 視界ルールの上位。敵チームのスナップショットから完全に消える |
| 予測移動 | クライアントが自機のみローカル即時移動 → スナップショットと照合(誤差>60pxでスナップ、以下はlerp収束)。実測ドリフト~20px |
| キャスト検証 | ターゲット座標はサーバーが射程380pxにクランプ。CD/マナ/スタンは全てサーバー側ゲート |
