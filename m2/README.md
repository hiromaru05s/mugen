# M2 — マッチループ完成 (SPEC §5/§6)

M1(スキルプリミティブ)の上に**1マッチの全要素**を実装したスライス:
成長 → 経済 → 封印装置 → 枯死圧 → ドラゴン戦 → RP精算。死=脱落(観戦)。

## 動かし方(要 Node 18+)
```bash
cd m2/server
npm install
node index.js        # ws://localhost:2569 (M0/M1と併走可)
```
`m2/client/index.html` をブラウザで開く → 職選択。複数タブで対戦(最大6人=3v3)。
操作: WASD/矢印移動・クリックorSpace攻撃・1-4(E/R/T)スキル・5ポーション・F購入/装置解除・G砥石。

## マッチフロー(サーバー権威)
| 時間 | イベント |
|---|---|
| 0:00 | バンドマップ(半径1400px・深部ほど強いモブ/高額宝箱)にスポーン |
| 1:00〜 | 外周から森が枯死(縮小)。枯死域内=DoT 22/s+**視界750→350px** |
| 4:00 | 封印解除 — ドラゴン出現(HP3500・フェーズ3段階・予兆AoE) |
| 〜8:00 | 討伐 or 全滅 or 時間切れ → **RP=チーム与ダメ割合×1000** をresultで配布 |

## M2の新規要素
- **成長**: モブ/宝箱/キルでxp・gold。Lv(+13%/Lv)・gold(+atk係数)・砥石(+8%累積、価格1.5倍逓増)
- **経済**: 商人3体(ポーション80G/砥石)。盗賊はgold+50%。キル奪取30%
- **封印装置(サーバー検証QTE)**: クライアントがミニゲーム実行、サーバーは
  `gimStart→gimDone` の**所要時間下限(盗賊2.0s/他3.2s)・装置60px以内・解除中の被弾なし**を検証(SPEC §4)。
  報酬=チーム対竜与ダメ+12%累積+120G/30xp
- **ドラゴンv0**: HP66/33%でフェーズ移行(予兆間隔2.6→2.0→1.7s、同時予兆1→2個)。
  与ダメはチーム別積算しHUDにライブ%表示
- **DEVモード**: `M2_DEV=1` で起動するとdevTeleport/devTime等のチートメッセージ有効(統合テスト用。本番無効)

## 統合テスト済み(コンテナ内・実サーバー)
